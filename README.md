RUSTLINE is an open-world crime game set in a desert highway town at dusk. You play Rosa Vega, a smuggler truck driver, running three jobs for Coyote the warehouse fixer: haul cargo to the gas station, sneak contraband to the motel via dirt roads while dodging a police checkpoint on the highway, and survive a wanted-3 manhunt before vanishing into a hideout in the sand hills. Steal cars, outrun patrols, fight on foot, and watch the sun go down over the dunes. Built with vendored Three.js, fully offline, all assets procedural and original.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or just open `game/index.html` in a desktop browser. No build step, no network requests.
